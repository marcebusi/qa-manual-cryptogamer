# BUG-005 — Estado del checkout no se resetea al cerrar en paso intermedio

| Campo | Detalle |
|---|---|
| **ID** | BUG-005 |
| **Módulo** | Checkout |
| **Severidad** | P2 — Mayor |
| **Estado** | Abierto |
| **Fecha** | 2026-10-27 |
| **Reportado por** | Marcelo Busignani |
| **Caso relacionado** | TC-CHK-007 |

---

## Descripción

Al cerrar el modal de checkout en cualquier paso que NO sea `success`, el estado interno del modal (paso actual, vendedor seleccionado, datos de envío, método de pago) **no se reinicia**. La próxima vez que el usuario abra el checkout, lo encontrará en el mismo paso donde lo dejó, con los datos anteriores pre-llenados.

---

## Pasos para reproducir

1. Iniciar checkout
2. Paso 1: Seleccionar un vendedor (ej: por la lista)
3. Paso 2: Verificar resumen
4. Paso 3: Completar nombre, email y teléfono
5. Cerrar el modal haciendo clic en el botón "X" o en el backdrop oscuro
6. Reabrir el checkout inmediatamente

---

## Resultado actual

El modal se abre en el **Paso 3 — Envío** con el vendedor ya seleccionado y los campos del formulario pre-llenados con los datos del intento anterior.

---

## Resultado esperado

Al cerrar el modal (sin completar la compra), debería resetear al **Paso 1 — Vendedor** con el formulario limpio.

---

## Impacto

- **UX:** Confuso para el usuario que quiere empezar de cero.
- **Datos:** Si el usuario cambió de decisión (otro vendedor, diferente método de envío), puede confirmar sin darse cuenta que usó los datos previos.

---

## Causa raíz (análisis de código)

En `CheckoutModal.tsx`, la función `handleClose` solo hace el reset cuando el paso actual es `'success'`:

```typescript
const handleClose = () => {
  closeCheckout()
  if (step === 'success') {
    // ✅ Solo se resetea al completar la compra
    clearCart()
    setTimeout(() => {
      setStep('seller')
      setSellerSubStep('choose')
      setSeller(null)
      setShipping(null)
      setPayMethod(null)
      // ...etc
    }, 300)
  }
  // ❌ Si step !== 'success', no hay reset
}
```

---

## Solución sugerida

Ejecutar el reset en todos los casos (no solo en `success`):

```typescript
const handleClose = () => {
  closeCheckout()
  if (step === 'success') clearCart()
  
  // Reset siempre, con delay para que la animación de cierre termine
  setTimeout(() => {
    setStep('seller')
    setSellerSubStep('choose')
    setSeller(null)
    setShipping(null)
    setPayMethod(null)
    setOrderNumber('')
    setOrderId('')
    setComprState('idle')
    setComprUrl('')
    setErrors({})
    setForm({ name:'', email:'', phone:'', address:'', city:'', province:'Buenos Aires', postal:'' })
  }, 300)
}
```
