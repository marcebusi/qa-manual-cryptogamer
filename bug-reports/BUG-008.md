# BUG-008 — Ruta 404 no muestra página de error personalizada

| Campo | Detalle |
|---|---|
| **ID** | BUG-008 |
| **Módulo** | Navegación / Routing |
| **Severidad** | P3 — Menor |
| **Estado** | Abierto (a verificar) |
| **Fecha** | 2026-10-27 |
| **Reportado por** | Marcelo Busignani |

---

## Descripción

La ruta comodín `*` está configurada para renderizar `<NotFoundPage />` en `App.tsx`. Sin embargo, si `NotFoundPage` no está implementada con un mensaje claro y CTA de retorno al home, el usuario puede quedar "atrapado" en una URL inválida sin saber cómo volver.

---

## Pasos para reproducir

1. Navegar a cualquier ruta inválida: `http://localhost:5173/pagina-que-no-existe`

---

## Resultado esperado

- Página 404 con mensaje claro: "Esta página no existe"
- Botón o link "Volver al inicio"
- Título de página `<title>404 - No encontrado`

---

## Resultado actual

_(A verificar en ejecución)_ — El componente `NotFoundPage` existe en el router pero su implementación visual/UX debe verificarse.

---

## Notas

Este bug es de severidad P3 (menor/cosmético). Tiene impacto directo en la experiencia de usuario al escribir URLs incorrectas o seguir links rotos.

---

## Archivos relacionados

- `frontend/src/App.tsx` — línea con ruta `*`
- `frontend/src/pages/NotFoundPage.tsx` — implementación a revisar
