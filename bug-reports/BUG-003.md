# BUG-003 — No hay límite máximo de cantidad en el carrito

| Campo | Detalle |
|---|---|
| **ID** | BUG-003 |
| **Módulo** | Carrito |
| **Severidad** | P2 — Mayor |
| **Estado** | Abierto |
| **Fecha** | 2026-10-27 |
| **Reportado por** | Marcelo Busignani |
| **Caso relacionado** | TC-CART-007 |

---

## Descripción

La función `updateQuantity` en `CartContext.tsx` no valida un límite superior para la cantidad de unidades por producto. Un usuario puede incrementar la cantidad de un producto hasta valores arbitrariamente altos (ej: 999 unidades), incluso si el stock disponible es 1.

---

## Pasos para reproducir

1. Agregar cualquier producto al carrito
2. Abrir el carrito y hacer clic en "+" repetidamente
3. Incrementar la cantidad hasta, por ejemplo, 50

**Alternativa vía código (para verificar sin esperar):**
```javascript
// DevTools Console
const cartItems = JSON.parse(localStorage.getItem('cart_items'))
cartItems[0].quantity = 9999
localStorage.setItem('cart_items', JSON.stringify(cartItems))
location.reload()
```

---

## Resultado actual

La cantidad se puede incrementar sin límite. El carrito muestra qty: 9999 y multiplica el precio sin ninguna advertencia.

---

## Resultado esperado

Debería existir un límite máximo de cantidad, ya sea:
- Basado en el stock real del producto (`product.stock`)
- Un tope arbitrario de negocio (ej: máximo 10 unidades por producto)

---

## Impacto

- **Negocio:** Se pueden generar órdenes con cantidades imposibles de cumplir.
- **Backend:** La creación de la orden puede fallar si el backend valida stock, causando una experiencia de usuario pobre.

---

## Causa raíz (análisis de código)

En `CartContext.tsx`:

```typescript
const updateQuantity = (id: string, qty: number) => {
  if (qty <= 0) {
    removeFromCart(id)
    return
  }
  // ❌ No hay validación de qty máxima
  setItems(prev =>
    prev.map(i => i.product.id === id ? { ...i, quantity: qty } : i)
  )
}
```

La validación de stock solo ocurre en `addToCart` con `product.inStock`, pero `updateQuantity` no tiene ningún tope.

---

## Solución sugerida

```typescript
const MAX_QUANTITY_PER_ITEM = 10

const updateQuantity = (id: string, qty: number) => {
  if (qty <= 0) {
    removeFromCart(id)
    return
  }
  const capped = Math.min(qty, MAX_QUANTITY_PER_ITEM)
  setItems(prev =>
    prev.map(i => i.product.id === id ? { ...i, quantity: capped } : i)
  )
}
```
