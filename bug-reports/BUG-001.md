# BUG-001 — Carrito no se limpia al cerrar sesión

| Campo | Detalle |
|---|---|
| **ID** | BUG-001 |
| **Módulo** | Carrito / Autenticación |
| **Severidad** | P2 — Mayor |
| **Estado** | Abierto |
| **Fecha** | 2026-10-27 |
| **Reportado por** | Marcelo Busignani |
| **Caso relacionado** | TC-CART-006 |

---

## Descripción

Al cerrar sesión (`logout`), el contenido del carrito persistido en `localStorage` bajo la clave `cart_items` **no se elimina**. Si otro usuario usa el mismo dispositivo/navegador, verá el carrito del usuario anterior al iniciar sesión o al abrir la tienda.

---

## Pasos para reproducir

1. Autenticarse con `test.customer@cg.com`
2. Agregar 2 productos al carrito
3. Cerrar sesión (logout)
4. Abrir DevTools → Application → Local Storage → `http://localhost:5173`
5. Verificar la clave `cart_items`

---

## Resultado actual

```
cart_items → [{"product": {...}, "quantity": 2}, ...]
```
La clave permanece en localStorage con los productos del usuario anterior.

---

## Resultado esperado

`cart_items` debería eliminarse o vaciarse durante el proceso de logout para proteger la privacidad del usuario.

---

## Impacto

- **Privacidad:** Un familiar, compañero de trabajo o cualquier persona que use el mismo dispositivo puede ver los productos que otro usuario tenía en el carrito.
- **UX:** Un nuevo usuario que inicia sesión ve el carrito "pre-cargado" sin haberlo llenado.

---

## Causa raíz (análisis de código)

En `AuthContext.tsx`, la función `logout()` elimina el token pero no limpia el carrito:

```typescript
// AuthContext.tsx — función logout()
const logout = () => {
  localStorage.removeItem('cg_token')
  setUser(null)
  // ❌ No llama clearCart() ni elimina 'cart_items' de localStorage
}
```

En `CartContext.tsx`, la función `clearCart()` existe y hace exactamente lo necesario:

```typescript
const clearCart = () => {
  setItems([])
  localStorage.removeItem('cart_items')
}
```

---

## Solución sugerida

En `AuthContext.tsx`, llamar a `clearCart()` desde el contexto del carrito, o bien importar y usar directamente:

```typescript
const logout = () => {
  localStorage.removeItem('cg_token')
  localStorage.removeItem('cart_items') // fix: limpiar carrito
  setUser(null)
}
```

---

## Workaround

Manualmente limpiar `cart_items` desde DevTools → Application → Local Storage, o abrir el carrito y eliminar los productos manualmente antes de cerrar sesión.
