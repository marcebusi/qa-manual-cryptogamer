# BUG-004 — Incrementar cantidad de ítem ya agregado no verifica stock

| Campo | Detalle |
|---|---|
| **ID** | BUG-004 |
| **Módulo** | Carrito |
| **Severidad** | P2 — Mayor |
| **Estado** | Abierto |
| **Fecha** | 2026-10-27 |
| **Reportado por** | Marcelo Busignani |
| **Caso relacionado** | TC-CART-002 |

---

## Descripción

`addToCart` verifica `product.inStock` únicamente al agregar el producto por primera vez. Al incrementar la cantidad de un ítem ya en el carrito (usando el botón "+" o llamando a `addToCart` de nuevo), el check de `inStock` es ignorado: el código toma la rama `existing` y simplemente incrementa `quantity` sin verificar disponibilidad.

---

## Pasos para reproducir

1. Agregar un producto al carrito (stock disponible, pasa la verificación inicial)
2. Modificar el producto en la DB para marcarlo como `inStock: false`
3. Sin recargar la página, hacer clic en "+" en el carrito para incrementar la cantidad
4. El producto se incrementa a qty: 2 sin ninguna advertencia de stock

---

## Resultado actual

La cantidad del producto se incrementa sin verificar el estado actual de stock.

---

## Resultado esperado

Al intentar incrementar la cantidad:
- Si `inStock: false`, debería mostrarse un mensaje ("Sin stock disponible")
- Si hay stock parcial, debería limitarse al stock disponible

---

## Impacto

Un usuario puede llegar al checkout con un producto fuera de stock en el carrito. El backend puede rechazar la orden, causando una experiencia frustrante.

---

## Causa raíz (análisis de código)

En `CartContext.tsx`:

```typescript
const addToCart = (product: Product) => {
  setItems(prev => {
    const existing = prev.find(i => i.product.id === product.id)
    if (existing) {
      // ❌ Rama "ya existe": solo incrementa, sin check de inStock
      return prev.map(i =>
        i.product.id === product.id
          ? { ...i, quantity: i.quantity + 1 }
          : i
      )
    }
    // ✅ Rama "nuevo": sí verifica inStock
    if (!product.inStock) {
      console.warn('Producto sin stock')
      return prev
    }
    return [...prev, { product, quantity: 1 }]
  })
}
```

---

## Solución sugerida

Mover la validación de `inStock` fuera de la condición `existing`:

```typescript
const addToCart = (product: Product) => {
  if (!product.inStock) return // validar siempre, no solo en el primer add

  setItems(prev => {
    const existing = prev.find(i => i.product.id === product.id)
    if (existing) {
      return prev.map(i =>
        i.product.id === product.id
          ? { ...i, quantity: i.quantity + 1 }
          : i
      )
    }
    return [...prev, { product, quantity: 1 }]
  })
}
```
