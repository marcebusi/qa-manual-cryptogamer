# BUG-006 — Validación de email acepta "@" como valor válido

| Campo | Detalle |
|---|---|
| **ID** | BUG-006 |
| **Módulo** | Checkout — Formulario de envío |
| **Severidad** | P2 — Mayor |
| **Estado** | Abierto |
| **Fecha** | 2026-10-27 |
| **Reportado por** | Marcelo Busignani |
| **Caso relacionado** | TC-CHK-005 |

---

## Descripción

La validación del campo email en el formulario de envío del checkout usa `String.includes('@')` en lugar de una expresión regular o validación de formato. Esto permite que valores como `@`, `x@`, `@x` o `@@` pasen la validación y se incluyan en el payload de la orden.

---

## Pasos para reproducir

1. Iniciar checkout y llegar al Paso 3 — Envío
2. Ingresar en el campo Email: `@`
3. Completar Nombre: `Test User`, Teléfono: `1122334455`
4. Seleccionar un método de envío
5. Hacer clic en "Continuar al pago"

---

## Resultado actual

El sistema acepta `@` como email válido y avanza al Paso 4 — Pago. Si se confirma la orden, el `customer.email` en la DB será `@`.

---

## Resultado esperado

El sistema debe rechazar el email con un mensaje: "Email inválido" y no avanzar al paso de pago.

---

## Impacto

- **Datos:** Órdenes se crean con emails de cliente inválidos, rompiendo cualquier notificación por email posterior.
- **Negocio:** El vendedor no puede contactar al cliente para coordinar el pago/envío.

---

## Causa raíz (análisis de código)

En `CheckoutModal.tsx`, función `validateShipping()`:

```typescript
const validateShipping = () => {
  const e: Record<string, string> = {}
  // ...
  if (!form.email.includes('@')) e.email = 'Email inválido'
  // ❌ Solo verifica presencia de '@', no formato completo
  // ...
}
```

---

## Solución sugerida

Usar una expresión regular básica para validar el formato:

```typescript
// Validación simple pero suficiente
const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/
if (!emailRegex.test(form.email)) e.email = 'Email inválido'
```

O usar la validación nativa del navegador (cambiar `type="email"` y verificar `validity.valid`):

```typescript
if (!form.email.match(/^[^\s@]+@[^\s@]+\.[^\s@]+$/)) e.email = 'Email inválido'
```
