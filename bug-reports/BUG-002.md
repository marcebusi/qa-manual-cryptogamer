# BUG-002 — Precio del carrito no se congela al momento de agregar

| Campo | Detalle |
|---|---|
| **ID** | BUG-002 |
| **Módulo** | Carrito |
| **Severidad** | P2 — Mayor |
| **Estado** | Abierto |
| **Fecha** | 2026-10-27 |
| **Reportado por** | Marcelo Busignani |
| **Caso relacionado** | TC-CART-004 |

---

## Descripción

El `totalPrice` del carrito se calcula usando el campo `product.price` en tiempo real desde el objeto del carrito. Si un administrador cambia el precio de un producto mientras ese producto está en el carrito de un usuario, el total del carrito **cambia silenciosamente** sin notificación al usuario.

---

## Pasos para reproducir

1. Agregar el producto "PlayStation 5" (precio: $500.000) al carrito
2. Como admin, cambiar el precio del producto a $600.000 via `PATCH /api/products/:id`
3. Sin recargar la página, verificar el total del carrito del usuario

> **Nota:** La reproducción exacta requiere que el carrito haga refetch del catálogo o que los objetos en `cart_items` referecien datos actualizados. El efecto ocurre con certeza si el usuario recarga la página — el precio en localStorage refleja el valor viejo, pero si el componente re-fetcha el producto, usará el nuevo precio.

---

## Resultado actual

El total del carrito puede variar entre la sesión actual y una sesión posterior sin que el usuario lo sepa.

---

## Resultado esperado

El precio debería "congelarse" (`lockedPrice`) al momento de agregar el producto al carrito, igual que lo hace el `orderId` en el checkout. Si el precio cambia, debería mostrarse una alerta al usuario antes de proceder al checkout.

---

## Impacto

- **Negocio:** El usuario puede llegar al checkout con un total diferente al que vio al agregar los productos.
- **Confianza:** Genera desconfianza si el total cambia de forma inesperada.

---

## Causa raíz (análisis de código)

En `CartContext.tsx`:

```typescript
// totalPrice se calcula con el precio actual del producto
const totalPrice = items.reduce(
  (sum, { product, quantity }) => sum + product.price * quantity,
  0
)
```

El objeto `product` en `items` es el que se guardó en localStorage al agregar, pero si el carrito se hidrata con datos nuevos, el precio puede haber cambiado.

---

## Solución sugerida

Guardar el precio al momento de agregar como `lockedPrice`:

```typescript
// CartContext: agregar lockedPrice al item
const addToCart = (product: Product) => {
  setItems(prev => {
    const existing = prev.find(i => i.product.id === product.id)
    if (existing) {
      return prev.map(i => i.product.id === product.id
        ? { ...i, quantity: i.quantity + 1 }
        : i
      )
    }
    return [...prev, { product, quantity: 1, lockedPrice: product.price }]
  })
}

// totalPrice usa lockedPrice
const totalPrice = items.reduce(
  (sum, { lockedPrice, quantity }) => sum + lockedPrice * quantity, 0
)
```
